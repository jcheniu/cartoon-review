CARTOON REVIEW / GUIDE

标注操作说明

选卡通风格，同时保持原图主体不失真。

返回标注 →
  1. 选择一组。输入 0-24 或 450-474 等连续 25 张范围，点“应用”。
  2. 按顺序比较。从左到右是候选 A、候选 B、输入原图。检查轮廓、五官、姿态和主要颜色。
  3. 选择合格情况。仅 A、仅 B、都合格或都不合格；都合格时选偏好，都不合格时勾选“颜色”和／或“姿态”。
  4. 保存并上传。修正英语描述，点“保存并下一张”。未满 25 张时保存草稿，不创建提交。满 25 张后先保存 JSONL，最后一次修改后合并约 30 秒，再自动提交 GitHub；成功后显示“已上传”及文件链接。
  5. 保留导出文件。本组标完自动下载 000_024.jsonl 等文件，也可提前手动导出。连接失败时浏览器保留标注并自动重试。
  6. 修改或恢复。切换“已标注”修改，完整组保存后会合并连续修改并自动提交新版本；内容未变化时保留原版本；换设备可以逐组导入 JSONL。

结果存在哪里？

公开保存到 GitHub 的 result/round_1 下，每个浏览器有独立的会话文件夹。同一组使用 xxx_xxx.jsonl 命名；页面显示“已上传”表示已提交到 GitHub。浏览器也保留副本。

上传还未成功怎么办？

保持页面打开，网络恢复后会自动重试。也可先导出本组 JSONL。清理浏览器前请确认上传完成或保留下载文件。

多人如何分配？

发送带范围的链接，例如 450–474 组。不同会话不会覆盖彼此的结果；同一图的不同意见由负责人合并。
